# MarketBot — клиентский мод (Fabric, Minecraft 1.21.11)

Работает на твоём аккаунте, на сервер ничего ставить не нужно. Читает общий чат и личные
сообщения, а отвечает **только в ЛС** (`/msg ник текст`, шаблон настраивается).

## Сборка

Нужны Java 21 и Gradle 9.2+ (Loom 1.14).

```
gradle wrapper --gradle-version 9.2.0     # один раз, если нет gradlew
./gradlew build                            # Windows: gradlew.bat build
```

Готовый мод: `build/libs/marketbot-1.0.0.jar` (файл `-sources` не нужен).
Положи его в `mods/` вместе с **Fabric API**.

Если проект не собирается — самый надёжный путь: сгенерируй пустой проект на
https://fabricmc.net/develop/template (Minecraft 1.21.11, Mojang mappings) и
скопируй в него папку `src/` из этого проекта.

## Как это работает

Игрок пишет в общий чат `$$$баланс` / `$$$б` / `$$$balance` / `$$$b` — бот отвечает ему в ЛС.
В ЛС префикс не нужен: достаточно `баланс`.

| Команда игрока | Что делает |
|---|---|
| `баланс`, `б`, `balance`, `b` | показать баланс |
| `помощь`, `help` | список команд |
| `магазин [название]`, `shop` | список магазинов / товаров магазина |
| `инфо <id>`, `info <id>` | описание товара |
| `купить <id> [кол-во]`, `buy` | оформить заказ (списывает баланс) |
| `перевод <ник> <сумма>`, `pay` | перевод другому игроку |
| `заказы`, `orders` | свои последние заказы |
| `топ`, `top` | топ балансов |

Язык ответа выбирается по команде: русская команда — русский ответ, английская — английский.

## Меню

**Right Shift** (меняется в Управление → MarketBot) или команда `/mb`.
Вкладки: Главная, Магазины, Товары, Заказы, Балансы, Настройки.

## Команды владельца

`/mb` — меню · `/mb on|off` · `/mb reload` · `/mb bal <ник>` · `/mb add|take|set <ник> <сумма>`
· `/mb ban|unban <ник>` · `/mb orders` · `/mb done <id>` · `/mb cancel <id>`

## Важно: формат чата у каждого сервера свой

Бот находит ник и текст через регулярки (Настройки → Парсинг чата). По умолчанию подходят
`<Ник> текст`, `Ник » текст`, `[Префикс] Ник: текст` и типичные ЛС. Если бот не реагирует:
включи «Отладка чата» — в твой чат будут выводиться сырые сообщения, и по ним легко
подогнать регулярку.

Деньги внутри бота — отдельный баланс (файл `config/marketbot/data.json`). Во вкладке «Игроки» можно искать игроков из списка сервера и известных боту, менять баланс и управлять чёрным списком.

Во вкладке «Пополн.» настрой точный шаблон сообщения сервера о переводе (регулярное выражение с группами `player` и `amount`) и включи автопополнение. Игрок пишет `$$$пополнить 100` и переводит владельцу 100 валюты. Бот зачислит деньги, когда увидит совпадающее системное сообщение, и отправит одно спасибо в ЛС. Заявка действует 10 минут и удаляется при отключении. Без заявки перевод автоматически не зачисляется.

Форматы сообщений HolyWorld и ReallyWorld нужно проверить на конкретном сервере. Отладка чата поможет получить точные строки. Системное сообщение само по себе не гарантирует, что его содержимое нельзя подделать через чат сервера: перед включением проверь формат и убедись, что другие игроки не могут имитировать уведомление.

Заказ не выдаётся автоматически: тебе приходит уведомление в чат, ты отдаёшь товар
в игре и жмёшь «Выдано» (игрок получает уведомление в ЛС). «Отмена» возвращает деньги.

Не злоупотребляй: следи за правилами сервера насчёт автоответчиков и частоты сообщений
(пауза между ответами настраивается).
