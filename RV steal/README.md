# KillerKC2 client

Клиентский мод для Minecraft Java 1.21.11 и Fabric. Проект находится в разработке; это ещё не полная копия ReallyVisuals.

## Установка

Установите Fabric Loader и Fabric API для Minecraft 1.21.11. Скачайте артефакт `killerkc2-client` из успешного запуска GitHub Actions и положите JAR в папку `mods`.

Настройки сохраняются в `config/rvsteal.properties`. В версии 0.3 ESP рисует собственные экранные рамки и подписи поверх мира. У игроков и монстров отдельно настраиваются имя, HP, экипировка, чары и дальность (16–128 блоков). Данные доступны только для сущностей, загруженных сервером. В версии 0.4 меню оформлено по присланному образцу: тёмная боковая панель, поиск по всем модулям и две колонки карточек (одна на узком экране). В Render отдельно отключаются Watermark, Hotkeys HUD, Potions HUD и Staffs HUD. Hotkeys показывает активные модули с назначенной клавишей; Potions — эффекты и время; Staffs — имена с признаками административного ранга в TAB, без гарантии обнаружения скрытого персонала. Визуальная проверка меню и виджетов в игровом мире ещё не выполнена.

## Активация

При первом открытии меню введите бессрочный админский ключ `KillerKC2`. Активация сохраняется в конфигурации. До активации модули, бинды и HUD не исполняются. Это локальная офлайн-проверка, которую можно обойти изменением клиента; сервер лицензий, выдача других ключей и отзыв доступа пока не реализованы.

Меню открывается правым Shift и закрывается Escape. ПКМ по модулю открывает настройки и назначение бинда (после нажатия кнопки бинда нажмите клавишу; Delete удаляет назначение, Escape отменяет). Right Shift зарезервирован для меню. Бинды действуют в мире при закрытых экранах. У Player Aura и Mob Aura независимые режимы Legit (плавный поворот камеры) и Rage (атака без поворота камеры).

Настройки по умолчанию выключены. Аура атакует ближайшую доступную цель после восстановления удара, в пределах обычной дистанции взаимодействия и при прямой видимости; подсветка работает только для загруженных сущностей. Auto Tool переключает инструмент в хотбаре и оставляет его выбранным.

## Возможности версии 0.5

<!-- coderabbit-ai-generated:v1 -->

<!-- coderabbit-ai-generated-section:v1:fd22342ac7142fbb4868d76f794a20d77c343d7526a4d62af3cf7ec2d56d4f54 -->

В Render доступны World Theme (готовые темы и цвета неба, тумана и облаков), Ambient Particles, Item ESP, Target HUD и No Hurt Cam. Target HUD показывает цель под прицелом или цель ауры, её HP, надетую броню и до двух эффектов.

<!-- /coderabbit-ai-generated:v1 --> В Combat есть Auto Totem: он перемещает тотем из инвентаря во вторую руку, когда инвентарь закрыт. Это не гарантирует срабатывание на каждом сервере.

ПКМ по Player ESP или Mob ESP открывает настройки: цвет рамки, текста и обводки в формате `#RRGGBB`, толщина, заливка, масштаб подписей и вещей, отступ, углы рамки, полоска HP, дистанция, линии и фон подписей. Настройки сохраняются отдельно для игроков и мобов. Блоки и сущности отображаются только в загруженных чанках. Block ESP показывает количество найденных блоков и ход сканирования; в его настройках есть наборы, цвет и список ID блоков (через запятую). Изменение набора заменяет предыдущий список.

Night Vision осветляет клиентскую световую карту и не добавляет настоящий эффект игроку. Совместимость с шейдерами и сторонними модами рендеринга не гарантирована. No Hurt Cam отключает качание камеры при уроне. Для настройки цвета замените шесть цифр после `#` в поле. Настройки модулей открываются ПКМ, переключение страниц — стрелками внизу.

## Возможности версии 0.6

В Combat модуль Hitboxes расширяет область прицеливания игроков на выбранную величину в блоках с каждой стороны: ПКМ по карточке открывает настройку. Удары по-прежнему проверяются сервером; расширение на клиенте не гарантирует попадание. Legit-аура удерживает выбранную цель и плавнее поворачивает камеру.

В меню слева: **HUD editor** позволяет перетаскивать виджеты мышью и сохраняет их расположение относительно размера экрана; **Configs** копирует код настроек в буфер обмена или загружает его из буфера. Код можно отправить другому пользователю. Импорт заменяет текущие настройки, ключ активации в код не входит. **Hide client** приостанавливает функции и скрывает интерфейс; пять отдельных нажатий F7 возвращают их в прежнем состоянии. Это скрывает работу мода в игре, но не удаляет JAR и не скрывает его от проверок файлов.

## Версия 0.7: вкладки, профили и конструктор

Модули разнесены по Combat, PvE, Movement, ESP, World и HUD. Custom содержит свои кнопки, Tools открывает Configs, HUD editor и Function builder. Меню — правый Shift, настройки карточки — ПКМ.

Configs позволяет сохранять именованные профили, загружать, выбирать следующий и удалять их. Файлы `.kc2` находятся в `.minecraft/config/killerkc2-profiles`. Обмен через буфер включает свои кнопки и бинды, но не ключ активации. Загрузка заменяет текущие настройки.

В Function builder укажите название, например `Ночной набор`, и действия: `ночное зрение; координаты`. Допустимо `включить ночное зрение; автоспринт`. Список действий открывается отдельной кнопкой. Карточка появляется в Custom: ЛКМ управляет всеми её действиями, ПКМ назначает бинд и открывает отдельные настройки модулей набора. До 24 кнопок, по 12 действий. Для изменения сохраните функцию под тем же именем; для удаления введите её имя.

Конструктор объединяет существующие действия. Он не превращает произвольное русское описание в Java-код, не создаёт новые виды настроек и не выполняет скрипты. Базовые модули можно переключать независимо; нажатие пользовательского тумблера задаёт его состояние всем действиям набора.

Кэшируется список базовых модулей, обработка пустых биндов пропускается. Block ESP делает паузу 20 тиков после полного прохода, найденные блоки проверяются раз в 5 тиков. Новые блоки могут появляться с задержкой полного прохода плюс пауза. Измеренного прироста FPS нет; специализированные моды оптимизации клиент не заменяет.

Windows-установщик и инструкции — в `../launcher`. GitHub Actions собирает JAR и EXE отдельными артефактами.
