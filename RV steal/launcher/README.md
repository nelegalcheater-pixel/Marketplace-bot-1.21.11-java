# KillerKC2 Launcher для Windows

<!-- coderabbit-ai-generated:v1 -->

<!-- coderabbit-ai-generated-section:v1:5009ffb205a6ddd569ac6589c90e9ca6135a1e09b53c98af5df9f07b4937d416 -->

EXE запускает Minecraft 1.21.11 с Fabric и KillerKC2 самостоятельно. При первом запуске скачиваются игровые файлы, библиотеки и ресурсы; потребуется интернет и место на диске.

## Использование

1. Установите Java 21 (или новее) для Windows x64.
2. Запустите EXE, введите ник из 3–16 латинских букв, цифр или `_`. Если Java не найдена, укажите полный путь к `java.exe`.
3. Нажмите «Запустить игру» и оставьте консоль открытой до запуска. Файлы игры и моды находятся в `%APPDATA%\.minecraft`.
4. Чтобы добавить свой мод, выберите JAR и нажмите «Добавить мод». Существующий файл с тем же именем не перезаписывается. Нужны моды для Fabric 1.21.11.

Используется локальный офлайн-ник: доступна одиночная игра и серверы без проверки аккаунта. Вход Microsoft и серверы с проверкой аккаунта не поддерживаются. Старые копии KillerKC2 заменяются по ID мода. Совместимый Fabric API и другие моды сохраняются; другая версия API или дубликаты требуют ручного устранения конфликта. Сборка для Windows x64, выполнение EXE на Windows ещё не проверено.

Скрипт собирает мод и тесты, копирует JAR и Fabric API в assets, запускает Go-тесты и компилирует Windows EXE. GitHub Actions `Build KillerKC2 client` публикует `killerkc2-client` и `killerkc2-windows-launcher`.

После подготовки assets для просмотра интерфейса выполните из `launcher`: `go run . --preview --port 8088`. Установка и запуск в этом режиме отключены. Страница слушает loopback; изменяющие запросы требуют случайный токен процесса. Рабочий установщик не следует публиковать как сетевой сервис.
