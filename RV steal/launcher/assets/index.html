Установи KillerKC2 и Fabric API, затем открой свой Minecraft Launcher и выбери профиль Fabric 1.21.11.

Нужны установленный Minecraft Launcher, Java 21 и Fabric Loader 1.21.11. Вход в Microsoft-аккаунт выполняется в Minecraft Launcher.

Установка в %APPDATA%\.minecraft\mods. Проверь и убери старые копии мода и дубликаты Fabric API перед запуском.

Окно консоли EXE должно оставаться открытым, пока используешь эту страницу.
